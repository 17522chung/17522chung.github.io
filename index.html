End-to-end pipeline · RSNA 2026, first author

Measuring brain DTI biomarkers without nonlinear registration

Nonlinear registration to a template makes diffusion-MRI biomarkers unreliable in edge cases, so I designed a model that samples them without that step.

Hover to read more

Standard pipelines nonlinearly register each brain to a template first, which fails in exactly the atrophied brains clinicians care about. My hypothesis was that we could skip registration: networks find 13 white-matter tract cores in each scan's own space. I built the whole ML pipeline around this, including slice selection, ROI regression, age- and sex-normed percentiles and GPU tractography, and designed and compared several U-Net-based architectures for the ROI drawer. It is now going through FDA clearance. On 784 public repeat-scan pairs, it was 3.5× more repeatable than the standard PSMD marker (±11.2% vs ±39.8%) and ~10× faster (9 s vs 89 s), at a modest cost in discrimination (AUC 0.80 vs 0.84).Figures: my RSNA 2026 talk, OASIS-3 data used under the OASIS data use agreement.

Differentiable rendering · CVPR 2026, co-author · SNU ICL

DiffBMP: images made of images

Applying DiffBMP to consecutive frames causes temporal flicker, so I extended it to video with warm starts, stuck-primitive removal and freezing.

Hover to read more

I built Dynamic DiffBMP, the video extension: warm-start each frame from the previous one, remove primitives that get stuck and block gradients, and freeze regions that don't change. Across 17 videos this cut temporal flicker (tLP) by 53% with no loss in fidelity, and I also contributed structure-aware initialization. Looking into why primitives get stuck, I hypothesized that colliding per-pixel gradients keep them in local optima. I then ranked them by per-pixel gradient magnitude instead, which is unpublished follow-up work. Paper · Project · CodeVideo: diffbmp.com demo. Figures: DiffBMP paper (Fig. 2, Fig. 4, Table 4).

Weak supervision · AIRS Medical

Pseudo-label generation to bootstrap spine MRI lesion segmentation

Open datasets have no lesion segmentation labels, so I generate pseudo-labels from classification labels to train a first model, and annotators only correct its predictions.

Hover to read more

I'm building a spine MRI product on my own, starting with deciding which measurements matter clinically. The bottleneck was labels: open datasets only say whether each disc is abnormal. I used several weakly supervised strategies to turn those weak labels into pixel-level training labels (classification → segmentation) with no manual annotation. That sets up a human-in-the-loop flywheel: once a model proposes plausible masks, an annotator only makes small corrections, and each round of corrections trains the next model. The figure shows candidate labels for one herniated disc. I also built a pseudo-labeling toolkit that my team has since adopted.Image: public SPIDER lumbar-spine dataset.

Robustness · Evaluation · AIRS Medical

Improving a brain volumetry model's robustness to acquisition shift

A model that did well on held-out data gave inconsistent results for the same patient across scanner settings. A label-free benchmark found the cause, and physics-informed augmentation fixed it.

Hover to read more

I first tested whether standard OOD detectors could catch these failures. They flagged novelty, not failure, so I measured failure directly. I built a label-free benchmark of same-subject scan pairs, each changing one acquisition setting, which traced the errors to an intensity shortcut at tissue boundaries. I led the work end to end, and the physics-informed augmentations I designed fixed most of the drift at a small in-distribution cost. Both the benchmark and the fix shipped in production. Details are withheld at my employer's request.

Evaluation without ground truth · AIRS Medical

Evaluating models on a task with no ground truth

Any spot inside a tract core is equally valid, so hand-drawn ROIs can't serve as ground truth. I built a harness that evaluates the sampled values themselves.

Hover to read more

Scoring the DTI model by overlap with a radiologist's drawing penalizes it for choosing a different spot that is just as valid: in the case shown, Dice is only 0.06, yet mean FA is 0.423 vs 0.425. I built an evaluation harness that judges what clinicians actually use, the measured value, along axes that need no golden label: does a rescan give the same number, does it reach the same group-level conclusions as a human reader, does it carry the clinical signal, and does it ever fail silently. It changed decisions. A version that was geometrically more accurate turned out to be less repeatable, so we stopped optimizing for geometry.Image: public IXI dataset (CC BY-SA 3.0).

Vision-language models · post-training

Learning VLM reasoning for zero-shot brain anatomy segmentation

A VLM trained only on structure names struggles with structures it never saw, so this model reasons from anatomy instead. Given a point in a brain MRI, it first writes what it sees (position, side, shape, signal) and only then names the structure. Every one of those words is computed from label maps, so each step can be checked. The same data then serves as fine-tuning targets, preference pairs, and rewards for reinforcement learning.

The plan is to extend it to finding a region from a lesion description, reaching a verdict by reasoning, and a segmentation model that outputs a 3D mask through a [SEG] token, so that any requested structure can be segmented zero-shot.

In progress · data pipeline and baselines done, model training next

Generative models · training data

Generating labeled training data when labels are scarce

A model that places ROIs on diffusion-MRI slices had only a few hundred hand-drawn examples to learn from. Instead of tuning the model again, I tried making more data: a two-stage generator that produces a realistic color-FA slice around the ROI disks I ask for, built from an encoder-decoder that compresses slices to latents and a diffusion UNet that generates latents conditioned on an ROI disk map and category.

The decoder that produces pixels never sees the label, which prevents label leakage. I then checked that it really puts anatomy where asked, and found a failure no automatic check caught: some samples came out as empty, dark frames, which I only spotted by looking.

Paused · the generator works; not yet used for training
