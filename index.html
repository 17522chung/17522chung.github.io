End-to-end pipeline · RSNA 2026, first author

Measuring the brain without warping it

Diffusion-MRI biomarkers break when every brain is forced onto a template. I removed the template.

Hover to read more

Standard pipelines warp each brain onto a template first, which fails in exactly the atrophied brains clinicians care about. My hypothesis was that we could skip the warp: networks find 13 white-matter tract cores in each scan's own space. I built the whole ML pipeline around this, including slice selection, ROI regression, age- and sex-normed percentiles and GPU tractography, and it is now going through FDA clearance. On 784 public repeat-scan pairs, it was 3.5× more repeatable than the standard PSMD marker (±11.2% vs ±39.8%) and ~10× faster (9 s vs 89 s), at a modest cost in discrimination (AUC 0.80 vs 0.84).Figures: my RSNA 2026 talk, OASIS-3 data used under the OASIS data use agreement.

Differentiable rendering · CVPR 2026

DiffBMP: images made of images

A CUDA renderer that fits thousands of bitmap primitives to a target in under a minute.

Hover to read more

I built Dynamic DiffBMP, the video extension: warm-start each frame from the previous one, remove primitives that get stuck and block gradients, and freeze regions that don't change. Across 17 videos this cut temporal flicker (tLP) by 53% with no loss in fidelity, and I also contributed structure-aware initialization. Looking into why primitives get stuck, I found that their per-pixel gradients cancel when summed. I then ranked them by per-pixel gradient magnitude instead, which is unpublished follow-up work. Paper · Project · CodeVideo: diffbmp.com demo. Figures: DiffBMP paper (Fig. 2, Fig. 4, Table 4).

0 → 1 · Weak supervision · AIRS Medical

From zero labels to a human-in-the-loop model

Pseudo-labels get a first model running fast, so people correct its predictions instead of drawing from scratch.

Hover to read more

I'm building a lumbar-spine MRI product on my own, starting with deciding which measurements matter clinically. The bottleneck was labels: open datasets only say whether each disc is abnormal. I used several weakly supervised strategies to turn those weak labels into pixel-level training labels (classification → segmentation) with no manual annotation. That is what gets the snowball rolling: once a model proposes plausible masks, an annotator only makes small corrections, and each round of corrections trains the next model. The figure shows candidate labels for one herniated disc. I also built a pseudo-labeling toolkit that my team has since adopted.Image: public SPIDER lumbar-spine dataset.

Robustness · Evaluation · AIRS Medical

Same brain, different numbers

A model that aced held-out data gave different answers for the same person when the scanner changed.

Hover to read more

I first tested whether standard OOD detectors could catch these failures. They flagged novelty, not failure, so I measured failure directly. I built a label-free benchmark of same-brain scan pairs, each changing one acquisition setting, which traced the errors to an intensity shortcut at tissue boundaries. I led the work end to end, and the physics-informed augmentations I designed fixed most of the drift at a small in-distribution cost. Both the benchmark and the fix shipped in production. Details are withheld at my employer's request.

Evaluation without ground truth · AIRS Medical

Grading a model when there's no right answer

Any circle inside a tract core is equally correct, so a hand-drawn label isn't ground truth.

Hover to read more

Scoring the DTI model by overlap with a radiologist's drawing penalizes it for choosing a different spot that is just as valid. I built an evaluation harness that judges what clinicians actually use, the measured value, along axes that need no golden label: does a rescan give the same number, does it reach the same group-level conclusions as a human reader, does it carry the clinical signal, and does it ever fail silently. It changed decisions. A version that was geometrically more accurate turned out to be less repeatable, so we stopped optimizing for geometry.Image: public IXI dataset (CC BY-SA 3.0).
